# OV-01 · 四路径触发矩阵（真机人工复核）

状态：UNVERIFIED

## 前置条件

1. `dist\Beautiful\Beautiful.exe` 为本次冲刺构建（含"动画子系统已挂载"日志行）。
2. 运行 `scripts\verify\anim-trigger-matrix.ps1` 自动取证，再按本文件做人工补格。
3. 日志在 `dist\Beautiful\logs\Beautiful-YYYYMM.log`；判据行前缀：`动画触发：` / `动画未播：`。

## 步骤（每格 ≈1 分钟）

对每个测试窗口（记事本、画图 mspaint、Chrome、一个 UWP 应用如计算器）：

1. **标题栏按钮**：点窗口右上角 ─ 按钮。
2. **Win+Down**：先把窗口最大化，再按 Win+↓。
3. **任务栏按钮**：任务栏上右键窗口按钮 → 最小化（或中键/点击已聚焦窗口的任务栏按钮）。
4. **Dock 点击**：点 Dock 上该窗口的图标。

## 期望现象

- 四格都看到：窗口画面被"吸进"Dock 图标（genie 脖子形），还原时反向流出；无黑闪/白闪/错位。
- 因缓存龄判废而不播时，日志必有 `动画未播：… 因=…`——**没动画且没日志才是 bug**。

几何对账：源=… GetWindowRect=… DWM=… 图标=… 结论=一致

## 已知事实（本机脚本取证，见 docs/evidence/anim/）

- 后台脚本抢不到前台锁时，"冷启动第一下"会因缓存无帧而不播（`因=到手时已最小化且缓存帧过期/缺失`）。
  真实使用中你必然先点过那个窗口（= 前台过 = 缓存有帧），此格应能播。
- 系统触发路径（标题栏钮/Win+Down/任务栏钮）属于"事后补偿档"：事件到手时窗口已缩下去，
  播的是前台缓存帧。允许 <100ms 的过渡痕迹（README 保真度分级已声明）。
