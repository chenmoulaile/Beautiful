# OV-09 · 自家窗口收拢退场

状态：UNVERIFIED

## 背景

v2.2 §4.4"自家窗口一律真动画"：设置/关于本机拥有自己的窗口循环，关闭时由
`OwnWindowAnimator` 把内容收拢（fade + scale→92%，easeInQuad，读 anim-params.json 的
close 时长/比例，可热加载调口味）后调真正的 Close；`OnClosing` 防重入保证保存设置等链路照常。

## 所有者核验步骤

1. 打开设置窗口 → 点 X（或 Alt+F4）：预期内容收拢淡出（约 150ms）后窗口消失；
   关闭前改过的设置应已保存（重新打开核对）。
2. 打开"关于本机"→ 关闭：同款收拢退场。
3. 收拢期间再点一次 X：不应重播动画（幂等）。
4. （口味）`config/anim-params.json` 里 `CloseDurationMs` 改 400：退场应变慢，无需重启。
