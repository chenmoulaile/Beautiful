# OV-08 · Dock 启动弹跳至首窗收口

状态：UNVERIFIED（收口匹配按"exe 基名=进程名"，跨进程时序需真机核）

## 背景

v2.2 §4.3"Dock 启动联动"：点 Dock 上未运行应用的图标 → 图标**反复弹跳**，
该应用首个顶层窗口出现（EVENT_OBJECT_SHOW 路径）时收口（当前这一次弹完自然落地）；
应用起了但不弹窗（托盘应用/启动失败）由 10s 超时兜底自动停。
设置项 `BounceEnabled`（默认开）；单击**已运行**应用仍是单次弹跳（macOS 语义不变）。

## 所有者核验步骤

1. 从 Dock 点一个未运行的应用（如计算器、记事本）：
   预期图标反复弹跳 → 首窗出现的当次弹完落地。日志 `启动弹跳收口：<进程名> 首窗已出现`。
2. 点一个 UWP/商店应用（进程名常与 exe 基名不一致）：
   预期 10s 内超时自动停（不永远弹）；日志无收口行——此为已知例外，如实记录。
3. 单击一个已运行的应用图标：预期仍是单次弹跳（约 600ms 一次），不进入持续模式。
4. 弹跳期间重复点击：进度重置不叠加（原 StartBounce 语义）。
