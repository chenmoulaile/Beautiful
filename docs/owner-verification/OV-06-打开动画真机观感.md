# OV-06 · 打开动画真机观感（SHOW + 占位帧）

状态：UNVERIFIED（agent 在非 Windows 机器开发，运行期目视不在本机做——如实交付核验）

## 背景

v2.2 §4.3：EVENT_OBJECT_SHOW 触发，占位帧设计（ghost 先以 t=0 全透明占住窗口矩形，
PrintWindow 后台重试 8ms×12，就绪当帧换入起播），200ms easeOutQuint，0.94→1.0 + 前段快速淡入。
设置项 `OpenAnimation` 默认开；`OpenAnimStyle` 默认 `inplace`，`fromicon` 为实验形态。

## 所有者核验步骤

1. 跑 dist 里那份 Beautiful（始终验证"用户跑的那份"）。
2. 从开始菜单/桌面分别打开：记事本、Chrome（或 Edge）、资源管理器新窗、一个 UWP 设置窗。
3. 观察每个窗口的**第一次**出现：应为"内容快速浮现、约 0.94→1.0 落位"，尾巴极缓；
   同一窗口 hide/show 回归（如托盘应用回显）不应再有动画。
4. 日志（logs/）检查：
   - `打开动画：占位帧就绪 层=… 重试=N 耗时=…ms`（N 通常 1-6）
   - `动画触发：源=OBJECTSHOW 层=… 引擎=openInPlace 时长=200 帧数=… P95=…`
   - 捕获彻底失败时应有 `动画未播：源=OBJECTSHOW 层=重试 因=占位帧捕获重试耗尽`，且窗口照常显示。
5. 设置页「动画」节：关掉"新窗口 macOS 式打开动画"→ 再开新窗应回到系统行为（瞬间出现）。
6. （可选实验）打开形态切 `fromIcon`：从 Dock 点一个未运行应用的图标，画面应从图标位置飞长到窗口位置；
   应用不在 Dock 时日志应出现 `fromIcon 缺 Dock 图标矩形，退化 in-place`。
