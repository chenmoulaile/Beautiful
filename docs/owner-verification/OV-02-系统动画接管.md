# OV-02 · 系统动画接管（SPI_SETANIMATION）

状态：UNVERIFIED（本机已证：**24H2 不响应这套老 SPI**）

## 背景

动画开启期间应临时关闭 Windows 的"缩向任务栏"动画（两条动画打架）。实现走
`SystemParametersInfo(SPI_GET/SETANIMATION)`，会话内生效、退出还原、不写注册表。

## 本机实测结论（开发机，Win11 24H2）

`tools/spi-probe` 探针：GET 与 SET 全部返回 FALSE、缓冲区不写入、GetLastWin32Error=0。
即本机系统**物理上不接受**这套开关，接管降级为"如实记录不接管"（日志可查）。

```
[WARN] 系统动画接管：本机系统不响应 SPI_GETANIMATION/SPI_SETANIMATION（新系统限制，探针 tools/spi-probe 可复现），本次不接管
```

## 所有者核验步骤

1. 运行 `tools\spi-probe`（`dotnet run --project tools/spi-probe`）：
   - 若输出 `GET ok=True minAnimate=1` → 你的系统支持，Beautiful 应能接管；
     跑一次最小化，确认只有 genie 一条动画（无第二条缩向任务栏的）。
   - 若输出 `GET ok=False` → 你的系统同样不支持，属**已知限制**：两条动画会并存。
2. 设置页「动画」节：切换"动画期间关闭系统「缩向任务栏」动画"，确认开关可保存
   （`config/settings.json` 里 `AnimSuppressSystemAnim` 变化）。
3. 退出 Beautiful（托盘 → 退出），确认系统动画偏好没有被永久改动。
