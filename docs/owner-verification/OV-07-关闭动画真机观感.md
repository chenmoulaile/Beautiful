# OV-07 · 关闭动画真机观感（DESTROY + 前台缓存帧）

状态：UNVERIFIED（默认不播=macOS 忠实；显式打开后才核）

## 背景

v2.2 §4.4：EVENT_OBJECT_DESTROY 触发（到手时窗口已销毁），画面只能取 2Hz 前台帧缓存，
龄超 `CloseCacheMaxAgeMs=1000`（config/anim-params.json 可调）判废不播。
设置项 `CloseAnimation` 默认关；自家窗口（设置/关于本机）不受它约束，一律真动画。

## 所有者核验步骤

1. 设置页「动画」节勾选"关闭窗口动画"。
2. 打开记事本，让它在**前台**待 ≥2 秒（缓存需要至少一张采样），然后点 X 关闭：
   预期为"内容收拢（→92%）+ 淡出，150ms"。
3. 打开一个从未进前台的窗口（后台进程弹的窗）再让它销毁：
   预期**不播**，日志 `动画未播：源=OBJECTDESTROY 层=缓存 因=关闭动画无可用缓存帧 …`。
4. 开着窗口静置 >1s 后切走焦点再关它：若缓存已过期，同样应不播且日志有因。
5. 打开/关闭设置窗口与"关于本机"：无论 `CloseAnimation` 开关，都应有收拢退场（自家窗口真动画）。
