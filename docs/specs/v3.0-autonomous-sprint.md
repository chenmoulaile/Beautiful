## 2. 不停顿协议（本文件的核心，违反即冲刺失败）

2. **原协作条款的转换规则**：三份规格里所有"所有者回执/录屏包/签字验收"条目，一律转换为三件事：① 你本机自证（§5）；② 自证不了的写 `docs/owner-verification/<编号>-<名称>.md`（含：验证脚本或步骤、期望现象、期望日志行、截图位）；③ 在 SPRINT-STATE.md 与最终报告标 UNVERIFIED。**然后继续**。
3. **唯一两种停止条件**：① 队列全部完成 → 出终版交付报告（§7）后停；② 环境硬阻塞（如非 Windows 机器无法跑 WPF）→ 先把所有不受阻塞影响的工作做完（Core 纯函数、单测、native 源码、脚本、文档），再出报告说明阻塞面。

### Q2 · 动画快赢包（纯 C#，目标：最小化触发率先到 100%）
> 依据 v2.2 §1 病灶假设 H2-H5/H8/H9，全部是 C# 层可修项，不等 native。逐项做，每项配日志证据行与单测：

1. **H9 挂载自检**：启动时 MinimizeAnimator（或其后继 Orchestrator）挂载状态写 INFO 日志+设置实值核对；挂载异常从 Warn 升级为显式降级声明（设置页可见"动画子系统未启用：原因"）。
2. **H4 系统动画接管**：动画功能开启期间 `SPI_SETANIMATION` 全局关闭（消除系统"缩向任务栏"动画与 genie 打架），退出/关功能还原原值（沿用 TaskbarManager 写回原始状态位模式）；设置项 `AnimSuppressSystemAnim` 默认开。
3. **H3 四触发路径时序修复**：Dock 点击路径保持"ShowWindow 前同步预捕获"；caption 按钮/Win+Down/任务栏路径接入 EVENT_SYSTEM_MINIMIZESTART 即时捕获 + **前景帧缓存兜底**（对当前前景窗口维持 ≤700ms 龄缓存帧，仅动画开启+非全屏时 2Hz 刷新，LRU：最近 1 窗全尺寸+4 窗半尺寸；缓存龄 >1500ms 判废不播）。触发源、捕获层（WGC 前的现有链：PrintWindow/屏幕/缓存）、龄值全部进日志。
4. **H5/H8 几何对账**：幽灵窗四角 vs 源窗口 DWM 扩展矩形 vs Dock 图标物理矩形（IconRectPhysical）三方对账日志行；发现 DPI 倍率错位即修（物理像素全程，换算走 MonitorGeometry 既有体系）；图标落点在放大场推挤时取**当帧实际渲染矩形**。
5. **H2 判废可见化**：所有"判废不播"路径输出结构化日志（`动画未播：源=Chrome 层=PrintWindow 因=纯色判废 取样=5x4`），并计数进 diag.ps1 判据行。
6. **参数初校**：GenieLamp 两阶段比例 0.30、总时长 500ms、还原 450ms、末端图标沉降反馈 120ms/0.94（v2.2 §5 参数表全量落 Core token + `anim-params.json` 热加载）。
7. **验收（本机自证）**：写 `scripts/verify/anim-trigger-matrix.ps1|cmd`：自动开记事本/画图（本机可得的最多窗口类别）×（Dock 点击路径可脚本驱动；caption 路径用 SendInput/UIA 驱动或人工步骤清单）逐格触发，收集日志判定 16 格矩阵触发率；本机全部可测格必须 100% 触发或有判废成因；截图/录屏（PowerShell+ffmpeg 或 Windows 自带 Xbox Game Bar 命令行不可用则用 `screen-capture` 脚本）存档 `docs/evidence/anim/`。

### Q3 · AnimLab + Native 渲染器 + genie 重建（v2.2 Stage B/C）
- 浓缩规格（全文见 v2.2 §2/§3/§4.1）：
  - **AnimLab**（tools/AnimLab，独立调参台，不进产品）：窗口列表+逐窗口 [genie 预览(不真最小化)]/[真最小化+genie]/[morph]/[open]/[close] 按钮；anim-params.json 热加载；帧时间图（P50/P95/max）；捕获来源指示；首帧延迟读数；一键导出诊断包。
  - **Native 渲染器**：`BN_Anim_CreateHost(monitor)` 每屏常驻全屏 DComp 宿主（WS_EX_NOREDIRECTIONBITMAP，点击穿透，空闲全透明零开销）；`BN_Anim_Play(host, texture, keyframes|曲线参数, effect, duration, speedMul)`；effect 先 genieMesh（顶点着色器网格形变）后 zoomMorph/openScale/closeFade；**数学单一事实源在 Core**（GenieLamp/GenieMesh 不动），跨边界传顶点还是传参数按"每帧传输 <0.5ms"实测定夺，传参数则双侧公式对拍单测；捕获链升级 WGC（IGraphicsCaptureItemInterop，IsBorderRequired=false）→DXGI→PrintWindow→屏幕，纯色判废保留；`AnimEngine: native|mesh|strips` 三态回退+native 崩溃熔断自动降级。
  - **重建验收**：AnimLab 里四类窗口 genie 预览全通（或判废有成因）；触发→首帧 <80ms；动画期间 P95 帧间隔 <20ms；强制渲染异常注入→熔断降级生效；空闲时宿主 CPU/GPU 占用读数进 diag。
- native 工具链在本机不可用时：代码+单测+CI 工作流照常提交，AnimLab 的 C# 部分先行，native 联调项标 UNVERIFIED-BUILD 进 owner-verification 包，**转 Q4 中不依赖 native 的条目**，队列末尾回收。

### Q4 · 还原 / 最大化 / 打开 / 关闭 / 批量（v2.2 Stage D-G）
浓缩规格（全文见 v2.2 §4.2-§4.6）：
1. **还原**（完整编排档）：`SW_RESTORE`+同批 `SetWindowPos` 挪虚拟屏外安全位（hold；**不用 SW_HIDE**；100ms 看门狗+应用抵抗检测→超时/抵抗即原子归位并退化 settle）→ 捕获活内容 → genie 反向 450ms → 同 vsync 原子归位+卸幽灵（内容零跳变）。系统触发路径=settle 交叉淡化（180ms）。hold 对 Chrome/Electron/UWP/≥10 主流应用做实测矩阵定主路，自锁位置应用名单入日志。
2. **最大化/还原缩放**：我方触发=off-screen hold 同款完整 morph（新内容从旧矩形 240ms easeInOutQuad）；系统触发（双击 caption/Win+Up/拖顶）=LOCATIONCHANGE 离散迁移判定（拖动/移动零误播，纯函数+单测）+settle 档；F11 无边框全屏=CoversMonitor 判定+与全屏避让联动（让位在动画 60% 进度起淡出）。
3. **打开**：默认 in-place scale 0.94→1.0+fade，200ms easeOutQuint；首帧竞态=**占位帧设计**（先装载窗口矩形+主题卡底 0 透明度幽灵，捕获重试 8ms×12 就绪当帧换入起播）；Dock 启动联动=图标弹跳至首窗 SHOW 事件收口；`OpenAnimStyle: inPlace|fromIcon`（fromIcon 默认关）；同进程 1s>3 窗只播首个。
4. **关闭**：默认不播（macOS 忠实，README 写明这不是没做完）；`CloseAnim=true` 时=前景缓存帧+EVENT_OBJECT_DESTROY 触发 fade+scale→92% 150ms（缓存龄<1000ms 才播）；我方触发关闭=先捕获后 WM_CLOSE 必播；**自家窗口（设置/关于本机/面板，及未来的访达）一律真动画**（拥有窗口循环，fade+scale 后 Close()）；WH_MOUSE_LL 关闭意图预捕获=v2 可选，做前先实测输入延迟，>2ms 放弃并记录数据。
5. **批量与系统场景**：风暴抑制（200ms 内 ≥4 最小化→整批不播，AnimPolicy 纯函数+单测）；锁屏/注销 WTS 事件清幽灵；全屏应用期间不播+捕获零轮询；explorer 重启自愈捎带幽灵宿主重建；并发幽灵 ≤3、同进程节流 300ms、排除清单、速度倍率 0.5-2.0+Shift 慢放全部落 Core AnimPolicy。
6. **验收**：v2.2 §4 各动画验收项中能本机自证的全部跑完（矩阵表+录屏存 docs/evidence/anim/）；不能自证的进 owner-verification 包。

## 4. 动画设计要点速查（v2.2 浓缩版，冲突处以 v2.2 全文为准）

- **成功定义**：四触发路径（Dock 点击/caption 钮/Win+Down/任务栏钮）×四类窗口（记事本/Chrome/Electron/UWP）触发率 100%（或判废有成因）；触发→首帧 <80ms；P95 帧间隔 <20ms；与 macOS 观感四要素齐（脖子/灯罩曲线/收进图标/图标沉降）；无黑闪白闪错位；降级方向永远是"不播动画、窗口功能零影响"。
- **保真度两档**（无注入红线下的诚实声明，写 README）：我方触发=完整编排档（预捕获/hold）；系统触发=事后补偿档（幽灵覆盖+settle），允许 <100ms 过渡痕迹。MyDockFinder/Lume 靠注入拿完整编排权，我们不注入，差距如实写。
- **架构分层**：Core 数学（GenieLamp/GenieMesh/ZoomMorphMath/OpenAnimMath/CloseAnimMath/AnimCurve/AnimChoreograph/AnimPolicy，全纯函数+单测）/ App 编排（AnimationOrchestrator 唯一收口，WinEvent 触发矩阵）/ Native 像素（DComp 宿主+D3D11 形变渲染+捕获链）/ AnimLab 调参台。
- **参数默认**（anim-params.json，全 Core token）：genie 500ms、灯罩两阶段 0.30、还原 450ms、morph 240ms、settle 180ms、打开 200ms/0.94 起、fromIcon 300ms/0.3 起（默认关）、关闭 150ms/0.92 终（默认关）、捕获重试 8ms×12、前景缓存龄 700ms/2Hz、并发幽灵 3、风暴阈值 200ms 内 4、速度倍率 1.0（0.5-2.0，Shift 慢放 ×3）。曲线：open=easeOutQuint、morph=easeInOutQuad、settle=easeOutQuad、close=easeInQuad、genie=灯罩既有。
- **红线**：不为动画扩注入白名单；hold 必有看门狗，绝不把用户窗口留在屏幕外；native 崩溃熔断降级 mesh/strips；动画子系统任何故障不得影响最小化/还原/最大化功能本身。

## 5. 自证体系（替代所有者回执，冲刺期间的验证方式）

1. **本机运行**：`scripts/install-local.cmd` 发布 dist\ 并**始终验证"用户跑的那份"**（README v3.6 流程教训：改的份≠跑的份）；每轮动画验证前重建重发。
2. **自动驱动**：PowerShell + UIA（System.Windows.Automation，仓库已有 UIA 使用先例）驱动测试窗口与 Dock 交互；SendInput 触发 caption/热键路径；无法脚本驱动的交互写成编号步骤清单自己执行并记录。
3. **证据存档**：`docs/evidence/anim/<日期>-<场景>/`：日志摘录、截图、录屏（可用则 ffmpeg gdigrab；不可用则关键帧截图序列）、AnimLab 诊断包、矩阵表 md。**每个 done 任务必须指向至少一份证据。**
4. **日志判据行**：新增 `动画触发：源=… 层=… 引擎=… 时长=… 帧数=… P95=…`、`动画未播：因=…`，diag.ps1 增设 [动画] 节汇总触发率/判废分布/帧统计。
5. **owner-verification 包**：`docs/owner-verification/README.md` 为索引，每项一文件（前置条件/步骤/期望现象/期望日志行/回填栏）——这是交付物，不是暂停理由。
